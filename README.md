Este site foi desenvolvido como projeto da disciplina de **Experiência Criativa: Navegando pela Engenharia de Software**. O objetivo do projeto era criar um site com o tema **Parques de Curitiba**, apresentando informações sobre alguns dos principais parques da cidade.

## Status do Projeto

Versão 1.0 finalizada para entrega acadêmica.

## Funcionalidades

* Carrossel com imagens dos parques
* Descrição dos parques citados
* Horário de funcionamento dos parques
* Tabela com os pontos positivos de cada parque
